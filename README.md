🚀 Быстрый старт
Требования
Python 3.8 или выше

Tkinter (обычно входит в стандартную поставку Python)

Установка и запуск
Вариант 1: Прямой запуск
bash
# 1. Скачайте файл программы
# 2. Запустите через Python
python traffic_light.py
Вариант 2: Создание ярлыка
bash
# Для Windows
python traffic_light.py

# Для Linux/macOS
python3 traffic_light.py
Вариант 3: Исполняемый файл
bash
# Установите PyInstaller
pip install pyinstaller

# Создайте EXE файл
pyinstaller --onefile --windowed traffic_light.py

# Запустите из папки dist/

Основные кнопки управления
Кнопка	Функция	Цвет	Описание
🔴 КРАСНЫЙ	Стоп	Красный	Полная остановка движения
🔴🟡 КРАСНЫЙ+ЖЕЛТЫЙ	Подготовка	Оранжевый	Подготовка к началу движения
🟢 ЗЕЛЕНЫЙ	Вперед	Зеленый	Разрешение движения
🟡 ЖЕЛТЫЙ	Внимание	Желтый	Предупреждение о смене сигнала
Кнопки режимов
Кнопка	Режим	Описание
▶️ АВТОМАТИЧЕСКИЙ	Авторежим	Циклическое переключение сигналов
⚠️ МИГАЮЩИЙ ЖЕЛТЫЙ	Ночной	Мигающий желтый для ночного времени
⏹️ ВЫКЛЮЧИТЬ ВСЕ	Выключение	Отключение всех сигналов
🚨 АВАРИЙНЫЙ РЕЖИМ	Авария	Мигающий красный сигнал
🌙 НОЧНОЙ РЕЖИМ	Тема	Переключение цветовой темы
