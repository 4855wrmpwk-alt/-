📱 # MacBook Air 13 - Светофор - Документация

🎯 # О проекте
MacBook Air 13 - Светофор — это элегантное приложение светофора, выполненное в минималистичном стиле Apple. Проект демонстрирует современный подход к созданию графических интерфейсов на Python с использованием Tkinter.

✨ # Ключевые особенности
🎨 # Дизайн в стиле macOS
•	Аутентичная цветовая палитра MacBook Air
•	Чистый минималистичный интерфейс
•	Поддержка темной и светлой темы
•	Типографика в стиле Apple

🚦 #Функциональность
•	Автоматический режим работы светофора
•	Ручное управление цветами
•	Таймер отсчета до смены состояния
•	Интуитивно понятное управление

🛠 #Техническая реализация
🏗 #Архитектура приложения
python

└── переключить_тему() - Смена темы

🎮 #Использование приложения
Основные элементы:
•	Три световых индикатора - Красный, желтый, зеленый
•	Кнопки управления - Точечные кнопки для ручного переключения
•	Кнопка "Авто" - Переключение автоматического режима
•	Кнопка темы - Переключение между темной и светлой темой
•	Таймер - Отсчет времени до следующей смены
Режимы работы:
1.	Автоматический режим - Классический цикл светофора
2.	Ручной режим - Прямое управление цветами

⚙️ #Настройки по умолчанию
Тайминги:
•	Красный свет: 5 секунд
•	Красный + желтый: 2 секунды
•	Зеленый свет: 5 секунд
•	Желтый свет: 2 секунды
Цвета (темная тема):
•	Фон: #1d1d1f (Темно-серый)
•	Текст: #f5f5f7 (Светлый)
•	Акцентные цвета: Mac Red, Mac Yellow, Mac Green

🔍 #Устранение проблем
Распространенные проблемы:
Проблема: Окно открывается слишком маленьким
Решение: Измените размер в строке self.root.geometry("500x700")
Проблема: Шрифты выглядят некорректно
Решение: Замените "SF Pro Display" на системный шрифт
Проблема: Программа не запускается
Решение: Установите Tkinter:

bash
# Ubuntu/Debian
sudo apt install python3-tk
